## Specifying defaults

Why is

```python
hostfile = pyre.properties.path()
hostfile.default = None
hostfile.doc = "the name of the file that describes the machine; none unless configured"
```

preferred over

```python
hostfile = pyre.properties.path(default=None)
hostfile.doc = "the name of the file that describes the machine; none unless configured"
```

Easier to not miss the default value (cosmetic, completely equivalent).

## Foundry methods

I am planning to eliminate the try/except blocks in foundry factories, so that the ImportErrors propagate.
What is the rationale for the try/except blocks in foundries (I copied from qed)?

```python
@pylith.foundry(tip="HDF5 data writer")

    try:
        from .DataWriterHDF5 import DataWriterHDF5
    except ImportError:
        # foundry will return None without generating an error if import fails for any reason.
        return
    __doc__ = DataWriterHDF5.__doc__
    return DataWriterHDF5
```
